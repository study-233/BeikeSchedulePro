# 手动考试验收

本次改动为源码编辑，未执行构建、测试、Lint、代码生成或设备操作。以下检查由开发者在自己的环境执行。

## 数据库与自动检查

- Room 版本由 6 升至 7，新增 `exam.source`：0 为教务导入，1 为手动。6→7 迁移仅追加默认值为 0 的列，保留原 ID 和其他字段。
- 先运行 `./gradlew :app:assembleDebug`，由 KSP 生成 `app/schemas/com.caeamer.beikeschedule.data.local.AppDatabase/7.json`，审查并纳入版本控制；不要手写 identity hash。现有 1–6 schema 保留。
- 对照 CI 执行 `./gradlew :app:testDebugUnitTest :app:lintDebug :app:minifyReleaseWithR8`，其中 `ExamDraftTest` 覆盖校验、待定展示、提醒计划和定向取消。
- 有设备或模拟器时执行 `./gradlew :app:connectedDebugAndroidTest`，重点检查 `ExamMigrationTest`、`ManualExamRepositoryTest`、`ManualExamViewModelTest`、`ManualExamUiTest`。迁移测试依赖已导出的版本 7 schema。
- Windows PowerShell 将上述 `./gradlew` 换为 `.\gradlew.bat`；沿用已有 SDK、JDK 和设备配置。

## 录入和编辑

1. 未登录、无考试记录时，顶部和空态均能添加，不触发教务登录。只填名称可保存，显示“手动”并归入“时间待定”。空白名称不可保存。
2. 逐步填写日期、开始、结束时间及地点、座位号、类型、备注。没有日期不能选时间，没有开始不能选结束；结束不晚于开始时提示错误。允许录入过去的考试。
3. 清空日期同时清空起止时间；清空开始同时清空结束。仅有开始时间时显示开始时间及“结束待定”，当日结束前不归入历史。
4. 点击手动考试编辑，字段完整回填；修改后取消不影响原记录，保存后 ID 不变。允许同名记录，教务考试没有编辑操作。
5. 输入过程中旋转屏幕，草稿和打开的弹窗保留；保存时按钮禁用，连续点击只保存一次。模拟数据库写入失败时保留草稿并显示错误，可重试。
6. 删除需要二次确认，取消后记录保留；已结束考试也能编辑和删除。大字号、小屏幕和键盘展开时可滚动访问全部字段及保存按钮。

## 同步隔离和提醒

1. 同时保留教务与手动考试；刷新成功、成功返回空列表、请求失败均不改动手动记录。切换课表、学期、退出教务登录后手动考试仍在。
2. 清除成绩缓存的确认文案明确保留手动考试；清理后只剩手动考试，成绩页继续显示获取数据引导。
3. 有日期但无时间的未来考试只安排前一天 20:00 提醒；补充开始时间后增加提前 1 小时提醒。无日期、已过去的考试不新增提醒。沿用未来 30 天调度窗口与已有权限处理。
4. 编辑日期、时间、地点或座位后，旧提醒取消，新提醒使用最新内容；删除后对应提醒取消。其他考试即使已到点但仍处于系统延迟投递队列，也不被误取消。
5. 将教务同步、清缓存与手动编辑交错执行，确认不会覆盖手动记录，最终提醒与数据库一致。
6. 模拟提醒调度失败：数据库修改仍成功，编辑弹窗关闭，提示可“重试提醒”；重试不再执行数据库增删改，不产生重复记录。
7. 覆盖安装旧数据库版本后确认考试 ID、名称、时间、地点、座位和备注保留；旧记录来源为教务，其他模块的数据保持原样。
