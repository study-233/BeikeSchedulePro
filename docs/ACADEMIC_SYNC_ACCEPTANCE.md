# 教务登录后自动同步验收

本轮仅编辑源码、测试源码与文档并进行静态差异审查，未运行构建、测试、Lint、应用、设备操作或学校服务请求。

## 源码测试

- `AcademicRequestsTest`：导入与教务数据入口、已有会话到达主页、重复请求去重、课表/成绩独立结果、预览/返回期间继续、手动刷新、配置重建、沿用 90 秒截止时刻、落盘期间重建与取消。
- `ScopedJwBridgeTest`：无标识、非法标识、过期、重复及取消后的桥消息不能写入。
- `AcademicDataSyncTest`：共用解析与缓存、空成绩、失败或异常考试响应不清缓存/提醒、有效空考试更新提醒、取消传播以及成绩隐私保持不变。
- 既有成绩、GPA、考试解析与提醒测试继续适用。未改变数据库结构或依赖版本。

使用仓库 wrapper 执行 CI 对应的 `:app:testDebugUnitTest`、`:app:lintDebug`、`:app:assembleDebug`、`:app:minifyReleaseWithR8`，上述测试尚未执行。

## 应用内验收（由开发者执行）

| 场景 | 预期 |
| --- | --- |
| 无会话时分别进入导入、我的教务账号、成绩刷新、考试刷新 | 展示登录页；完成认证后自动同步成绩、GPA、考试、学籍与学业进度 |
| 保留有效 Cookie 再进入以上入口 | 无需输入账号，进入主页即自动获取 |
| 重复主页回调、切换栏目、退后台再返回、页面重组 | 同一请求不会重复注入；普通页面切换不自行刷新 |
| 课表先返回，成绩仍在获取 | 立即显示原生预览，可确认导入；不跳成绩页，不创建第二个 WebView |
| 预览/保存/返回课表期间成绩返回 | GPA 与成绩缓存随后更新；校园中可见新数据，隐私开关不被打开 |
| 成绩先返回或失败，课表稍后返回 | 课表继续获取；成绩成功/失败状态独立显示 |
| 已有缓存时断网/请求失败/整次获取超时 | 本次任务结束，显示可重试状态，保留缓存，不自动循环重试 |
| 考试子请求失败或返回登录 HTML/错误 JSON | 保留旧考试及原提醒；课程提醒不变 |
| 合法空考试、空成绩 | 空考试可清除过期安排并重排提醒；空成绩提示未解析到，其他成功数据仍保存 |
| 抓取时旋转/配置重建 | 旧回调失效；只恢复未完成网络请求，原截止时刻不延长；已完成/正在落盘的数据不重抓 |
| 获取中退出网页回到原生页面 | 已启动成绩继续；未登录的等待任务取消；原生页面正常点击、滚动，无隐藏网页焦点或无障碍节点 |
| 获取中进入我的并退出账号或清缓存 | 取消对应请求；迟到结果不写入；退出账号保留此前已保存的数据 |
| 完成后再次手动刷新 | 创建新请求，允许更新新数据；保留当前成绩/考试栏目 |
| 登录后导入课程及小组件 | 课表仍需人工确认；隐藏课程、课程提醒和小组件刷新维持原行为 |

90 秒从自动抓取开始计算，供用户操作的登录等待不计入此限制。此机制是当前应用会话中的请求续接，不是后台定时同步；进程被系统终止后不承诺继续网络任务。
