# 清透布局改造验收清单

本次仅完成源码与测试源码修改，未运行构建、测试、Lint、应用或设备操作。以下步骤由开发者在现有环境执行。

## 自动检查

使用仓库 wrapper：macOS/Linux 为 `./gradlew`，Windows PowerShell 为 `.\gradlew.bat`。

依照 CI 分别运行 `:app:testDebugUnitTest`、`:app:lintDebug`、`:app:assembleDebug`、`:app:minifyReleaseWithR8`。Compose 设备测试通过现有 Android Studio 测试入口执行，签名发布构建使用开发者已有私有签名配置。

新增测试覆盖栏目迁移、导航访问键恢复与去重、学期草稿合并、日程闹钟清理和通知隔离、旧广播忽略、时段排序、考试结束判定，以及课程文字实际居中与底部位置。学期编辑设备测试覆盖取消、返回确认、配置恢复与失败后重试；详情设备测试覆盖来源消失后关闭及下拉关闭。

## 布局与手势

- 课表、校园、我的快速连续切换，选中底板连续移动；页面退出期间不接收点击或返回事件。
- 手势连续切周、周次菜单跳转、退后台后返回当前周、桌面小组件打开当前周，标题和日期一致，无从第一周滚到当前周的过程。
- 点击课程后立即返回；拖动详情时反向操作；内容未到顶部时只滚动内容，到顶部后可下拉关闭；关闭回到正确来源。
- 详情内隐藏或删除课程后淡出；旋转、数据变化或来源消失后不回跳到其他课程。
- 七天课表、冲突课程、长课程名、单节课、最大应用字号叠加大系统字号：日期固定，网格可滚动，教室与教师靠下居中且不覆盖标题。
- 自定义背景、强遮罩、模糊、深色主题分别检查；课表显示预览与实际卡片一致。
- 系统动画关闭与放慢两种设置下，返回和页面操作仍正常，无残留遮罩或导航锁。

## 设置与校园

- 从课表菜单和我的进入同一设置，显示与提醒即时保存；学期仅保存时提交，取消不改变数据，有修改时返回确认放弃。
- 有官方校历时调整备用日期，不改变官方教学周映射；总周数低于官方校历时保存进行校正。
- 上课提醒权限关闭后显示处理入口，从系统设置返回立即刷新状态。
- 校园栏目、楼栋选择、成绩筛选与滚动位置在切换及配置重建后恢复；主动换楼栋回到顶部。
- 空教室在上课中、课间、晚上全天结束时分别检查排序与收起状态；刷新失败保留已有内容。
- 成绩的统计、筛选、列表、学分进度顺序正确；纳入计算选择面板可独立滚动。成绩隐藏和退后台复位不回归。
- 考试当天结束后归入历史，缺少时间的考试仍可查看。登录、导入、缓存清理、退出登录和小组件入口保持可用。

## 覆盖升级

在测试安装中准备旧版课程、考试和日程记录，排入日程提醒并保留一条显示中的日程通知，再覆盖安装新版：

- 旧栏目 0、1、2、3 分别落到空教室、空教室、成绩、考试；重启后仍正确。
- 日程表和记录保留，数据库版本及 schema 不变。
- 启动、升级广播、开机后日程闹钟与通知消失；重复清理无副作用。
- 即使日程闹钟已到点但尚未投递，也应取消；延迟到达的旧日程广播不再展示通知。
- 课程与考试闹钟、通知、每日续排和小组件更新不受影响。

性能以真机发布构建的实际刷新率与稳定呈现为准，不预先承诺固定帧率。
