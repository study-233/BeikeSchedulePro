## 安装与升级

从本次 Release 下载签名 APK 安装，最低支持 Android 14（API 34）。新应用 ID 与原版的数据、偏好和登录会话相互独立。首次使用需重新登录、导入课表和成绩，并重新设置个人日程与提醒；不会自动迁移原版数据。无需卸载原版。

后续 BeikeSchedulePro 版本需保持相同应用 ID 和签名证书，并递增内部版本码，才能覆盖升级。
