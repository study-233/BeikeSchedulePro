## 安装说明

正式发布后，从本仓库 [Releases](https://github.com/study-233/BeikeSchedulePro/releases) 下载签名 APK 安装。当前配置最低支持 Android API 34。

本版使用新的应用 ID，首次安装视为新应用，与原版数据、偏好和登录会话相互独立。无需卸载原版，但需要在新应用重新登录、导入课表和成绩，并重新设置个人日程与提醒；不会自动迁移原版数据。

后续 BeikeSchedulePro 版本需要保持相同应用 ID 和签名证书，并递增内部版本码，才能正常覆盖升级。
