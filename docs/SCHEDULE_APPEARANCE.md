# 课表外观验证说明

入口：点击课表顶部学期名 → 课表外观，或“我的 → 课表 → 课表外观”。

## 源码变更

- 卡片展示课程名、地点、教师和单双周标记，缺失字段不占行。
- 课程字号可在 80%–160% 间以 5% 为步长调整，默认 100%。
- 行高根据课程跨度、字号和系统字体缩放计算；日期栏固定，网格支持上下滚动和左右切周。
- 图片使用系统选择器导入，本机处理方向和尺寸（最长边 2048 像素），存储于应用私有目录并排除云备份。
- 背景支持居中填满/完整显示、遮罩 0%–80% 和模糊 0–24；恢复默认背景不修改字号。
- 外观存储于 DataStore，课程数据库与教务接口不变。

## 人工验收

- 两个入口展示同一配置；滑块拖动实时预览、松手保存，关闭再打开与重启后保持。
- 姓名为空、地点为空、超长姓名、单节课程和冲突并排卡片：教师位于地点下方，长姓名单行省略，详情仍显示完整内容。
- 80%/100%/160% 字号叠加大系统字体：地点和教师不被挤出卡片；日期固定，节次列与课程同步滚动；底部课程可滚动至添加按钮上方。
- 隐藏周末、非本周课程、左右切周、长按空格添加课程、点击课程详情均可用。
- 手动选中非当前周后调整外观，保存配置不会主动切回本周，也不会改变提醒开关、提前时间和排期。
- 横图、竖图、带方向信息的照片分别验证两种填充方式、模糊、遮罩和深浅主题，导航与日期文字保持可读。
- 取消选图保留原配置；换图成功前保留旧文件；不可解码图片提示失败，旧背景仍可使用。
- 删除相册原图后已导入背景仍可使用；应用内部图片缺失或损坏时显示默认渐变，并可重新选择。
- 恢复默认背景同时重置填充方式、遮罩和模糊，字号保持不变。
