# App 自动更新验收

本文是待执行清单，不代表检查已经通过。代理仅编辑与审阅源码，不运行构建、测试、安装或设备操作。

## 更新来源与发布约定

- 使用 `study-233/BeikeSchedulePro` 的 GitHub 最新正式 Release，不接入教务会话，也不上传个人数据。
- 正式附件命名 `BeikeSchedulePro-v<版本号>.apk`。缺少标准命名时仅选择唯一 APK；缺失或歧义时转发布网页。
- APK 使用相同应用 ID、兼容的正式签名、更高的 `versionCode`，`versionName` 与 Release 标签对应。支持数字分段以及 `v` / `V` 前缀。
- APK 大小、包名、版本与签名在安装前验证；GitHub 提供 SHA-256 摘要时必须匹配。系统安装器仍负责最终签名与覆盖安装验证。
- 调试签名包不能直接覆盖安装正式签名包。正式覆盖安装验收需使用维护者已有的同签名旧包与新包；不要为验证更新而卸载有数据的应用。
- 原有版本需要先手动安装一次包含本功能的版本，之后才能使用应用内更新。

## 行为验收

| 场景 | 预期 |
| --- | --- |
| 首次启动、返回前台 | 距离上次检查尝试满 24 小时才自动请求；切页和旋转不重复请求 |
| 检查失败、断网、GitHub 限流 | 自动检查失败不弹窗；关于页显示错误，手动检查可立即重试 |
| 手动检查、忽略版本后手动检查 | 不受 24 小时或忽略设置限制；发现新版直接展示操作弹窗 |
| 无新版、旧版 Release、异常版本字符串 | 相同或旧版本显示已是最新；无法识别的版本报告失败 |
| 稍后提醒、忽略版本、重启 App | 提醒选择持久化；稍后至少间隔 24 小时；忽略版本不再自动提示，后续新版可提示 |
| 教务登录、导入、同步正在进行 | 更新弹窗暂缓展示；不抢占教务流程，不阻止下载继续 |
| Wi-Fi 点击立即更新 | 下载开始，显示已下载大小与进度；未经确认不使用移动数据 |
| 移动网络或计费 Wi-Fi 点击更新 | 显示大小与二次确认，可允许下载、仅 Wi-Fi 等待或取消；不允许漫游下载 |
| 下载中 Wi-Fi 切移动网络 | 未授权移动网络的任务暂停；已授权的任务可继续 |
| 断网再联网、切后台、系统回收、旋转 | 由系统管理下载，前台恢复同一个任务；不得重复下载 |
| enqueue 成功但任务 ID 未保存时退出 | 按应用专属目标文件找回任务，不创建第二份下载 |
| 取消、失败重试、空间不足、任务被系统移除 | 展示可理解的状态；重试前清理旧任务与文件；可退回网页下载 |
| 下载完成且 App 在后台 | 不自动拉起安装器；返回前台可看到安装入口；稍后处理保留有效 APK |
| APK 损坏、大小或摘要不符、错误包名/版本/签名 | 停止安装，显示原因；提供重试或发布网页入口 |
| 首次安装授权、拒绝后返回、再次点击安装 | 仅用户发起时进入授权页；授权后续接一次；拒绝不循环跳转 |
| 校验时旋转、切后台、教务流程打开 | 安装请求由当前前台页面处理，后台不拉起安装器，不使用旧 Activity |
| 系统安装取消或没有安装器 | 保留安装/网页入口，不误报升级成功 |
| 同签名覆盖安装成功 | 版本已更新；课表、手动课程、成绩和偏好保留；再次启动清理旧更新任务与 APK |
| 云备份和设备迁移 | 不备份更新任务记录和安装包；课表等既有备份规则保持原样 |

## 源码检查与用户执行项

新增 `AppUpdateTest` 覆盖版本比较、附件选择、限频与提醒、任务身份恢复、持久化往返及 APK 身份与签名兼容规则。真实网络、DownloadManager、FileProvider 和系统安装器行为需按上表在设备验证。

用户可在仓库根目录运行（Windows PowerShell）：

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug
.\gradlew.bat assembleDebug
.\gradlew.bat minifyReleaseWithR8
```

macOS / Linux 使用 `./gradlew`。同签名正式 APK 的构建仍需要维护者自己的签名配置。
